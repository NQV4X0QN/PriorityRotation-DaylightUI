# Priority Rotation (DaylightUI Plugin)

A plugin for [DaylightUI](https://github.com/dayightt/DaylightUI) on WoW: Forever.

- **Priority Rotation:** one key press casts the next ready spell from a list you build.
- **Hide Error Text:** choose which red error messages stay off the screen.
- **Mute Sounds:** choose which game sounds stay quiet.
- **Auto Equip:** puts on upgrades from your bags, by the quality levels you pick.

Its settings are in the DaylightUI options window, under **Plugins**.

## Requirements

DaylightUI. This plugin is not part of DaylightUI: please report problems here, not to the DaylightUI team.
